# Verse Typer

A browser-based typing game for memorizing Bible verses. Type the verse and
each letter turns green if it's right or red if it's wrong.

**Play it:** https://brandtdgarrison-svg.github.io/Verse-typer/

## Features
- Real-time, letter-by-letter feedback as you type
- Backspace to fix mistakes

## Built with
HTML, CSS, and vanilla JavaScript (no frameworks)

## Roadmap
This project is in early development. Planned features:
- Detect when a verse is finished
- Accuracy and words-per-minute stats
- Choose from multiple verses, or get a random one
- Memory modes that gradually hide words
