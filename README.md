# Verse Typer

A browser-based typing game for memorizing Bible verses. Pick a verse, type it
out, and each letter turns green if it's right or red if it's wrong.

**Play it:** https://brandtdgarrison-svg.github.io/Verse-typer/

## Features
- Real-time, letter-by-letter feedback as you type, with a blinking cursor
- Type directly onto the verse (no separate text box)
- Choose a verse from a dropdown, restart it, or jump to a random one
- Live stats: mistakes, accuracy, and words per minute
- Finish message with your total time and mistake count
- Verses are stored as data, so adding a new one is a single line of code

## Built with
HTML, CSS, and vanilla JavaScript (no frameworks or libraries)

## Roadmap
- Memory mode that gradually hides words as you improve
- Save best scores and custom verses between visits
- Visual polish for the buttons and verse picker
